# CL-NLP Lab

Lab work for the Computational Linguistics & NLP (CL-NLP) course. Each lab is a Google Colab notebook covering a specific topic.

## Index

| Lab | Title                     |
|-----|---------------------------|
| 1   | Data Analysis             |
| 2   | Basic Text Preprocessing  |

---

## Lab 1: Data Analysis

Exploratory data analysis on an employee dataset using pandas, matplotlib, and seaborn.

- 1.1 Average salary by department (bar chart)
- 1.2 Number of employees per department
- 1.3 Male vs female employee split (pie chart)
- 1.4 Salary distribution (histogram)
- 1.5 Experience vs salary (scatter plot)
- 1.6 Top 10 highest-paid employees
- 1.7 Highest salary per department
- 1.8 Employees earning above the overall average salary
- 1.9 Average experience per department
- 1.10 Age distribution (histogram)

## Lab 2: Basic Text Preprocessing

Cleaning and tokenizing raw text using plain Python, NLTK, and spaCy.

- 2.1 Lowercasing, punctuation removal, digit removal, whitespace cleanup
- 2.2 Word & sentence tokenization (regex, NLTK, and spaCy versions)
- 2.3 Stop-word removal
